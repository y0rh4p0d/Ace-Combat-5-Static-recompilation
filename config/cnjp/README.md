# cnjp configuration

Generated by `python -m cnjp port` from the US `config/` tree by
translating guest addresses to the `SLPS_254.18` executable.

Address map summary: 26388 intervals, 131 explicit overrides,
14 unresolved code ranges.

`pac_names.txt` is deliberately absent: it names members inside
`DATA.PAC` by name, and those names are the same in every region,
so the recompiled build reads `config/pac_names.txt` directly.
